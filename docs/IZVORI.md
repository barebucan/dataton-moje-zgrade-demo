# Izvori i metode

| Podatak | Izdavatelj i izvor |
|---|---|
| Adrese i geometrije zgrada | [Državna geodetska uprava](https://dgu.gov.hr/otvoreni-podaci-6596/6596) i [suradnici OpenStreetMapa](https://www.openstreetmap.org/copyright) |
| Energetski certifikati | [Javni izvadak iz registra izdanih energetskih certifikata](https://data.gov.hr/ckan/dataset/izvadak-iz-registra-izdanih-energetskih-certifikata) |
| Solarni potencijal | [Grad Zagreb, Solarna karta](https://gis.zagreb.hr/solarnaMapaZagreb/) |
| Obnova | [Popis operacija programa Konkurentnost i kohezija](https://data.gov.hr/ckan/hr/dataset/popis-operacija-financiranih-u-okviru-programa-konkurentnost-i-kohezija-2014-2020) i evidencije navedene uz pojedini zahvat |
| Modelirane poplave | [Hrvatske vode, Geoportal](https://www.voda.hr/hr/geoportal) |

Adrese i obrise povezujemo s tematskim zapisima. Karta razlikuje službene zapise, modelirane rezultate i orijentacijske procjene. Detalji zgrade pokazuju izvor, obuhvat i pravilo povezivanja za prikazani podatak.
